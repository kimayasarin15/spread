# MPS CD 25-26 T&1 Project 2 Spread 
## Trent Soto and Kimaya Sarin

For this project, we worked together to typeset Hooked on a Feeling, by Michael Rock. The article discusses the balance between rational and emotional design, where the latter has become increasingly dominant. 
We focused on making it fluidly responsive across multiple breakpoints going all the way from mobile to desktop. We did this by adding media queries in CSS to make sure each element could respond correctly to its size. We also created print styles to ensure our site could manifest in a physical form, keeping in mind the constraints for print.
